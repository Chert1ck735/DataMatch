# Архитектура DATA MATCH

Конвейер превращает журнал событий матча в оценку игрока с диапазоном. Каждый слой читает только результат
предыдущего, кэширует его с ключом «данные + конфигурация + код» и не пропускает дальше, если не прошёл свою проверку
(гейт). Все параметры и пороги — в [`configs/default.yaml`](../configs/default.yaml); полная методика с выводами —
[`METHODOLOGY.md`](METHODOLOGY.md).

```
L0 события, смены, время на льду ─▶ L1 шанс гола (xG) ─▶ L2 ценность ситуации V(s) ─▶ L3 вклад действия δ
                                                                                            │
          L6 диапазоны (бутстрэп матчей) ◀── L5 поправка на объём данных (эмпирический Байес) ◀┘
                     │
          outputs/test_ratings.csv ─▶ карточка игрока и карточка для клуба
                     └─▶ L7 проверка: повторяемость, прогноз, покрытие, сравнение с простыми
L4 (поправка на партнёров, RAPM) — эксперимент, в итоговую оценку не вошёл
```

## Слои

| Слой | Вход → выход | Метод | Проверка (гейт) | Код |
|---|---|---|---|---|
| **L0** Подготовка | события и смены → действия с шайбой, составы на льду, время на льду, разбиения | смена игрока, состав и отрезок между остановками — разные сущности; порядок по `seq`; неизвестное не превращается в исход | качество данных, совпадение времени на льду | `l0_*.py`, `stage_l0.py`, `splits.py` |
| **L1** Шанс гола | попытки броска → xG | турнир 8 моделей; выбран LightGBM (монотонный по расстоянию и углу, Optuna), 16 признаков; «нейтральный» xG против среднего соперника | Σ xG / голы: 95%-интервал накрывает 1; сравнение с сильнейшей моделью на отдельных фолдах | `l1_xg.py`, `stage_l1.py` |
| **L2** Ценность ситуации | состояния → V(s) | марковская цепь: клетка площадки 11 × 5 × время до конца периода × численность; редкие состояния сглажены к родителю; решение системы (I − Q)V = R; изотоническая калибровка | калибровка по децилям с поправкой Бонферрони; сравнение с бустингом | `l2_value.py`, `l2_procedure.py`, `stage_l2.py` |
| **L3** Вклад действия | действия → δ | δ = награда (xG броска) + σ·V(после) − V(до); σ = +1 шайба у своих, −1 у соперника, 0 остановка; потеря после не-броска делится α = 0,5 | вклады по отрезку складываются точно (до 10⁻¹⁶) | `l3_contrib.py`, `stage_l3.py` |
| **L5** Поправка на объём данных | вклады игрока за 60 мин по 5 составляющим → оценка O1 | эмпирический Байес по амплуа: θ̂ = μ + T(T + S)⁻¹(x − μ), шум S = σ²/TOI + ω²/матчи (по амплуа); метки HIGH/MEDIUM/LOW | правило приёма вариантов: повторяемость не хуже, покрытие в коридоре | `l5_shrink.py`, `stage_l5.py` |
| **L6** Диапазоны | O1 → `test_ratings.csv` | rating ± 1,96·√(апостериорная дисперсия + дисперсия моделей); модели xG и V переобучены на 200 бутстрэп-выборках матчей; правило «< 60 мин → LOW» | доля неудачных повторов ≤ 5% | `l6_*.py`, `stage_l6.py`, `scripts/apply_display_rules.py` |
| **L7** Проверка | train, половины матчей → отчёт | повторяемость (Спирмен–Браун), skill score против «только амплуа», покрытие диапазона другой половины, сравнение с очками/бросками/xG | правила приёма из конфигурации | `rating_validation.py`, `l7_*.py`, `validation.py` |
| L4 RAPM (эксперимент) | составы на льду → поправка на партнёров | гребневая регрессия; λ по перекрёстной проверке и по эмпирическому Байесу | повторяемость не хуже O1 — **не прошла** | `l4_rapm*.py` |

## Ключевые свойства

- **Без утечек:** признаки xG и V доступны до действия; время броска относительно гола не используется; модели
  ценности не знают личность игрока; подбор моделей — только на обучающих матчах.
- **Единицы:** все вклады и оценки — в ожидаемых голах (xG); оценка игрока — xG за 60 минут относительно среднего
  своего амплуа.
- **Воспроизводимость:** фиксированный seed, зафиксированные версии библиотек (`requirements.lock.txt`), кэш с ключом
  по данным, конфигурации и коду; ноутбук сверяет sha256 итогового файла.
- **Проверки кода:** тесты в [`tests/`](../tests/) (`pytest`), включая ручные расчёты для формул вклада и стягивания.

## Карточка игрока (вне рейтинга)

Отдельные поля с собственными пометками надёжности: WAR за сезон, роли и похожие игроки (GMM), оценка по ситуациям
5×5 / большинство / меньшинство, удаления (Пуассон–гамма), вбрасывания (Брэдли–Терри), физический профиль с шайбой.
Карточка для клуба (`outputs/card/club_ratings.csv`) — перцентиль в амплуа, вывод и надёжность словами; текст
собирается по шаблонам, без LLM. Код — `card_*.py`.
