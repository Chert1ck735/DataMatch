# Карта жизни проекта: что меняли и почему

Каркас слоёв (L0 → L1 → L2 → L3 → L5 → L6, проверка L7 сбоку, эксперимент L4) задан архитектурой 02.10 и
**не менялся**. Менялись правила внутри слоёв (после аудитов), выбор моделей (по турнирам), объём
дополнительных блоков (по времени и результатам) и подача (по ответам организаторов).
Главный принцип: **блок остаётся, только если обыграл более простой по заранее заданному правилу.**

## 2. Отходы от исходной архитектуры по слоям

| Слой | Было в архитектуре | Стало | Почему |
|---|---|---|---|
| L1 | бустинг или EBM; отдельные модели по численности | турнир 8 моделей; выбран LightGBM с подбором Optuna; модели по численности **отвергнуты во всех прогонах** | дробление выборки большинства/меньшинства; численность уже есть признаком |
| L1 | допуск Σ xG / голы ±2% | 95%-интервал бутстрэпа матчей должен накрывать 1 | жёсткий допуск уже шума числа голов; без проверки суммы ранее был принят CatBoost с переоценкой +4,2% |
| L1 | подбор и сравнение на одних фолдах | подбор — фолды 0–2, сравнение — фолды 3–4 | оптимизм подбора ≈ 20% выигрыша |
| L1 | сила соперника подставлялась средним | кросс-подгонка по матчам и точная интеграция («нейтральный xG») | подстановка занижала Σ xG до 0,96–0,98 и давала утечку |
| L1 | угол броска из-за линии ворот | видимый угол = 0 | иначе бросок из-за ворот получал шанс гола как с «пятака» |
| L1 | время броска как признак | только окна от предыдущего действия; время периода и Δt запрещены | отметка времени гола систематически позже: AUC одного Δt = 0,74 — утечка исхода |
| L2 | обучение ценности с весами 1/N | **единичный вес события** | 1/N зависит от будущей длины отрезка и ломает уравнение Беллмана; калибровка была 3/10 → стала 10/10 |
| L2 | гейт «10 децилей калибровки» | одновременные интервалы с поправкой Бонферрони | без поправки идеальная модель проваливала гейт ~40% времени |
| L2 | марковская — база, бустинг — претендент | выиграла **марковская** (бустинг лучше по R², хуже по калибровке) | правило «калибровка — обязательное условие» |
| L2 | калибровка V на внешнем блоке — гейт | диагностика (9/10) | блок уже просматривался ранними версиями и входит в итоговую подгонку |
| L2/L3 | вклад по калиброванной V | найдено смещение −0,0013 на действие; вариант «вклад по исходной V» проверен прогоном 2 — **отклонён** | повторяемость упала на 0,076 [0,042; 0,114]; правило: повторяемость не должна ухудшаться |
| L3 | вклад = выбор + исполнение, пасы «риск–награда», защита в своей зоне | не делалось, в план развития | ~1,5 дня работы; «ценность выбора» без трекинга смешана с невидимым контекстом |
| L4 | RAPM с командным эффектом — эксперимент | сделан в двух вариантах — **не принят** | повторяемость 0,04 и 0,29 при 0,61 у O1; литература: RAPM в хоккее шумный |
| L5 | общий шум σ², ω² | **шум по амплуа** (принят по правилу из 4 условий) | покрытие C/W/D стало 95,1 / 94,3 / 94,3% (было 92,7 / 91,9 / 98,2%) |
| L5 | метки HIGH/MEDIUM/LOW по доле собственного сигнала | + правило «< 60 мин → LOW „мало минут“» | на train при малом времени метка обещала больше, чем повторялось |
| L5 | — | стягивание недиагонали T_r (Ledoit–Wolf, из литературы) — **отвергнуто** | повторяемость упала (−0,011) |
| L6 | интервалы по перцентилям бутстрэпа | нормальное приближение; перцентили — только при B ≥ 1000; B = 200 | при B = 200 перцентили шумные |
| L6 | прогнозный интервал в файле | только в отчёте | в train нет дат — дрейф между сезонами не оценивается |
| L8 | роли (GMM), похожие игроки, сценарии, интерактивная карточка | роли с общей ковариацией, при неустойчивости — «тяготеет к»; похожие — сделаны; сценарии и интерактивная карточка — нет | время; роли неустойчивы на этих данных |
| L8 | текстовые карточки через LLM | **шаблоны без LLM** (`outputs/card/club_ratings.csv`) | воспроизводимо, текст не может «приукрасить» число, данные не уходят в облачный сервис |
| L8 | — | **добавлена** карточка для клуба: перцентиль в амплуа, вывод и надёжность словами, WAR за сезон | организаторы: «интерпретируемо для людей, далёких от данных — очень важно» |
| Ф | физический профиль, усталость как контекст | посчитаны скорость с шайбой и темп; все повторяемости < 0,3 → только уровень амплуа/звена | ненадёжно при ~4 матчах; без трекинга скорость видна только с шайбой |

## 4. Уроки первой версии

1. **Выбор модели шанса гола «EBM или LightGBM» менялся несколько раз** — их разница в пределах шума. Прогон с нуля
   на сервере снова выбрал EBM, но рейтинги почти совпали (Спирмен 0,996). Вывод: рейтинг от выбора модели xG почти
   не зависит.
2. **Первая победа EBM была артефактом утечки времени броска** — аудит утечек сработал.
3. **Победа CatBoost была артефактом цепочки сравнений** (сравнивался не с сильнейшей моделью) и принятой переоценки
   Σ xG +4,2% → отсюда правила «сравнение с сильнейшей» и «Σ xG по интервалу».
4. **Абляции признаков переворачивались от малых правок подготовки данных** → признак из спецификации убирается только
   при устойчивом вреде на нескольких сидах; итог — 16 признаков.
5. **Пороги заданы до результатов** (первый коммит). Правила, изменённые после аудитов (Σ xG, калибровка V),
   описаны выше как изменения.
