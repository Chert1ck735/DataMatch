# L2: контракт реализации и проверки

V — условное среднее знаковой суммы xG с текущего узла до подтверждённой остановки;
единица — ожидаемые голы. Смена команды меняет знак, не горизонт. Пропуск наблюдений
цензурирует цель, а не завершает игру. Базовый gamma=1. Дисконт и своё владение —
отдельные estimands, сравниваемые только с соответствующей собственной целью.

Вес физического события — единица в обучении, калибровке, дистилляции и оценке (решение
06.10.2026: вес 1/N зависел от длины segment, то есть от будущего исхода, и оценивал
E_w[G|s] вместо беллмановской V). Оценка использует каждое событие один раз (перспективы
вбрасывания по 0,5) и парный кластерный bootstrap матчей. Калибровка условного среднего
проверяется по bootstrap разницы наблюдение−прогноз в децилях с одновременными интервалами
(Бонферрони: совместный уровень 95%, по 99,5% на дециль). Константа обучается
только на train. XG-процедура для каждого фолда обучается без его проверочных матчей.
Внешний блок закрыт для выбора. Кэш включает таблицы узлов, xG-спецификацию, разбиение,
конфигурацию, версии библиотек и код зависимых слоёв.

Входные признаки не содержат actor/player/team IDs, исхода, x2/y2 броска либо собственных
часов броска. Геометрия — из rink_geometry.csv. Ссылки узлов — ID, а не позиции
отфильтрованного DataFrame. Структурные классы arrival/history, не прошедшие аудит P005,
не возвращаются в Markov скрытым путём. История допускает прошлые координаты.

Калибровка V обучается на match-cross-fit только тренировочной части; внутри неё
также переобучается xG. У обучаемой силы команды — собственная match-cross-fit,
при применении подставляется нейтральное значение 0. На вбрасывании применяется
точная антисимметрия: V(s)=(f(s)−f(mirror(s)))/2, без свободного intercept.
Вес физического события при зеркалировании не удваивается.

Совпавшие прогнозы распределяют свою квантильную массу между децилями одинаковой
долей для всех событий с этим прогнозом. Это исключает зависимость от порядка
матчей и пустые децили из-за ties; 95% match-bootstrap и требование всех децилей
сохраняются. Исключённые цели не загрязняют потери через 0×NaN.

`value --force` сравнивает кандидатов на фолдах 3–4 без их участия в обучении.
Затем весь конвейер xG→V переобучается для каждого dev-фолда: `dev_values` — OOF,
`test_values` — применение frozen dev-fit. Не использовать в L3 внутривыборочный V.
Дистилляция выигравшего GBM в таблицу сохраняется только при ухудшении MSE <1%
и прохождении калибровки. FQE требует отдельной оценки надёжности сумм игроков
в L3; дисконт и своё владение имеют другие цели. Не выполненные опции отмечаются
`not_run` в реестре и не выдаются за подтверждённые улучшения.

В dev_values `node` относится к переиндексированному графу development,
`source_node` — исходный глобальный ID train-графа L0. Для соединения с исходным
L0 используется source_node; match_id служит дополнительной проверкой. Разбиения
и эти внешние ключи входят в provenance.

OOF здесь означает обучение всей фиксированной xG→V-процедуры без своего матча.
Рецепт уже выбран на development и условно фиксируется; это не nested повторный
выбор моделей в каждом фолде и не независимая оценка качества выбранной системы.
Качество после выбора оценивается отдельным замороженным внешним контролем,
с оговоркой об историческом просмотре этого блока.

Неизвестные (цензурированные) цели исключаются без довзвешивания наблюдаемого суффикса:
событие с известной целью сохраняет единичный вес, цензурированные получают 0. Калибровка с менее чем двумя
эффективными матчами (также внутри дециля) inconclusive и не проходит gate.
